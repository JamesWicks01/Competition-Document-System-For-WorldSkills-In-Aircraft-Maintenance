# Competition-Document-System-For-WorldSkills-In-Aircraft-Maintenance
A Competition Document System For WorldSkills In Aircraft Maintenance For Final Year Dissertation as part of a BSc (Hons) Software Engineering 

## Setup
1. Unzip the folder and open the folder in your terminal
2. Run the following command `npm i` to install the starter packages that are required
3. Once finished, run the following command `npm run install-all` to install the application packages that are required
4. Once finished, run the following command `npm start` to start the application it then should automatically load the application in your default browser

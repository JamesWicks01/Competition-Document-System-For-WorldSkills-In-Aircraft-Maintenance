## Setup
1. Unzip the folder and open the folder in your terminal
2. Run the following command `npm i` to install the starter packages that are required
3. Once finished, run the following command `npm run install-all` to install the application packages that are required
4. Once finished intall the database located [here](https://github.com/JamesWicks01/Competition-Document-System-For-WorldSkills-In-Aircraft-Maintenance/blob/main/app/backend/newdatabase.sql)
5. Once finished, run the following command `npm start` to start the application it then should automatically load the application in your default browser
